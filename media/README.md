# FrontierOR figure

The light- and dark-theme SVGs in this folder plot the 30 final synthetic scheduling instance comparisons published in the [FrontierOR study](https://github.com/Venkat-RJ/openresearch/tree/main/frontieror/scheduling-study).

- `frontieror-instances.csv`: local copy of the study's published 30-instance table.
- `figure.py`: source that generates the figure from those instance records.
- `frontieror-light.svg` and `frontieror-dark.svg`: rendered figures.

This is a visualization of recorded comparison data, not a claim of factory cost savings or general superiority. Consult the study's protocol, limitations, and verification tools before interpreting the result.
